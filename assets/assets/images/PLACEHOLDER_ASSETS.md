# Placeholder image assets needed

Add these files to this folder before building (referenced in code as PLACEHOLDER comments):

- `mooo_logo.png`      - app logo (used in AppBar / NavigationRail leading, currently FlutterLogo stand-in)
- `default_avatar.png` - fallback avatar for users with no photo
- `default_group_icon.png` - fallback icon for group chats with no custom photo
- `media_error.png`    - optional fallback shown when a chat image fails to load

Any square PNG (e.g. 256x256) will work as a placeholder until real branding is ready.
